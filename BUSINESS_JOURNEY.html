Ringkasan Sistem

🔄

Bisnis Proses

Sistem vending machine digital yang menyediakan alur lengkap: akses pengunjung tanpa login, manajemen saldo, katalog produk, checkout, dan pelacakan transaksi secara real-time dengan pencatatan atas nama user Anonym.

👣

User Journey

Pengunjung langsung mengakses beranda tanpa login, menambah saldo, memilih produk, dan checkout. Transaksi tercatat sebagai user Anonym. Menu Transaction disembunyikan untuk pengunjung.

⚙️

Teknologi

Dibangun dengan stack teknologi modern: ASP.NET Core MVC, Entity Framework Core, PostgreSQL, dengan keamanan menggunakan BCrypt untuk hashing password.

Keunggulan Sistem

🔐

Autentikasi Aman

Login khusus SuperAdmin, password di-hash menggunakan BCrypt untuk keamanan maksimal

💳

Saldo Real-Time

Pembaruan saldo langsung terlihat setelah setiap transaksi

📊

Monitoring Transaksi

Pantau semua aktivitas transaksi secara real-time

📦

Manajemen Inventaris

Kelola stok produk secara efisien dan akurat

📧

Email & Digital Receipt

Pengiriman struk belanja otomatis via email dengan lampiran PDF (QuestPDF)

🛡️

OTP Login SuperAdmin

Login SuperAdmin dapat menggunakan kode OTP 6-digit yang dikirim via email secara real-time

📜

Auditable Reporting

Skema database Header-Detail untuk pelaporan transaksi yang mendalam

📋

Audit Log Terpusat

Catatan lengkap semua aktivitas sistem untuk keperluan audit
